# 🏅 India's Performance Analysis | Commonwealth Games 2026

## 📌 Project Overview
This project presents a data-driven analysis of India's performance at the Commonwealth Games 2026. Beyond the surface-level medal tally, this breakdown highlights performance efficiency, gender-wise gold conversion rates, and core discipline concentrations using Microsoft Excel.

---

## 📊 Key Highlights & Insights
* **Total Medal Tally**: 39 Medals (13 Gold, 17 Silver, 9 Bronze)
* **Gold Efficiency Engine**: Female athletes secured **61.5% of total Gold medals** (8 out of 13), demonstrating exceptional finish quality.
* **Core Concentration**: Over **87% of all medals** (34 out of 39) came from just three sports: Athletics, Boxing, and Weightlifting.
* **Top Gold Driver**: Boxing generated 7 Gold medals, with female boxers winning 5 of them.
